# Modder Notes

Lord's Ledger does not currently load external XML data packs. Extension work is source-level.

## Add Or Change Culture Labels

Edit `Source/Services/LedgerDataReader.cs`:

- `_adjectives` maps culture IDs to display adjectives.
- `_castleNouns` maps culture IDs to stronger castle nouns.

Keep these dictionaries case-insensitive.

## Add A New Warning Factor

Use this path:

1. Add fields to `Source/Models/FiefInfo.cs` if the UI/report needs to display new data.
2. Read the data in `Source/Services/LedgerDataReader.cs`.
3. Add warning logic in `ComputeWarning`.
4. Add risk contribution in `ComputeRisk` if it affects urgency.
5. Add issue/action text in `BuildPrimaryIssue` and `BuildActionHint`.
6. Add text output in `Source/Services/LedgerRenderer.cs`.
7. Add board output in `Source/Services/LedgerRenderer.cs` if needed.

## Add A Sort Or Filter

Use this path:

1. Add an enum value in `Source/Configuration/LedgerSettings.cs`.
2. Update the cycle modulus.
3. Add a display label.
4. Update `LedgerRenderer.SortGroup` or `PassTypeFilter`.

## Add A Board Field

Use this path:

1. Add the property to `Source/Models/LedgerBoardSnapshot.cs` or `LedgerFiefSnapshot`.
2. Set it in `Source/Services/LedgerRenderer.cs`.
3. Expose it in the matching view model.
4. Bind it in `GUI/Prefabs/TAOM_LordsLedger.xml`.

## Export Format

The export reuses the text report generated by `Source/Services/LedgerRenderer.cs`. Keep export-friendly content in the renderer rather than only in the board snapshot.
