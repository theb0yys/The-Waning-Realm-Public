# Retinues clan-colour compatibility patch

Independent compatibility project; not a suite system. Owns only the bridge
between Retinues custom equipment and TAOM clan-colour persistence.
Preserves module ID, assembly identity, Harmony ID and entry-point namespace.
No save data, equipment mutation, third-party source edits or asset ownership.

Entry: SubModule.cs. Package: SubModule.xml and the Release DLL.
Design and acceptance: documents/mods/retinues-compat/README.md.
Owner tests: Tests/Retinues.Regression.csproj. Native visual acceptance is separate.
